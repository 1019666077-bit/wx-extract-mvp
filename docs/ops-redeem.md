# 兑换码运营手册（人工收款）

本站是纯静态前端。**没有登录、没有后端、没有微信支付接口。**  
兑换码只是 `data/codes.json` 里的一份浏览器校验白名单，方便你人工收款后把课卖出去。

仓库是公开的。把下面流程当「防小白漏课」，不要当成安全系统。

## 卖什么、不卖什么

售卖话术只讲本站自学工具，不把 VOA 公版内容当付费版权卖。

- 卖：**打卡日历、错题本、第 6 课及之后的订阅解锁**（本站壳子与学习记录）
- 不卖：**免费的 VOA Learning English 视频/文稿本身**（公版，官网可看）
- 说明：第 1–5 课本站免费试学；开通后解锁本站已上线的后续课
- 避免话术：官方课程、VOA 授权、保证过级、永久版权

可参考一句：

> 这是非官方自学页。VOA 视频和文稿是公版，人人都能看。收费的是本站打卡、错题和第 6 课之后的解锁，方便你按计划学。

## 发码

1. 打开 `data/codes.json`，从白名单里取一条**还没发出去**的码。
   - 月付用 `plan: monthly`，格式 `LLE-M-XXXXXX`
   - 季卡用 `plan: quarterly`，格式 `LLE-Q-XXXXXX`
2. **只在微信私聊**发给该用户。不要发朋友圈、小红书、群公告、公开评论。
3. 提醒用户：打开开通页，把码粘进「兑换码」后点解锁。
4. 在你自己的表格里记下已发（见下一节）。

本仓库读者也能打开 `data/codes.json` 自己兑。因此：

- 把未发出的码当**可烧掉的库存**，不要当密钥
- 若怀疑泄露（码被陌生人兑走、或仓库被大量浏览），作废该批并生成新码后重新部署
- 每卖出一单后，可选：开一个后续 PR，从 `codes.json` 删掉已用码，减少库存暴露面

## 自备发码表（不要提交进仓库）

本地用表格或备忘录即可，例如：

| 日期 | 计划 | 码 | 是否已发 | 用户备注 |
| --- | --- | --- | --- | --- |
| 2026-09-05 | 月付 ¥39 | LLE-M-…… | 已发 | 微信昵称 / 备注名 |

**不要把这张表、未发出的码清单、或用户微信信息 commit 进仓库。**

## 码用尽后如何补货

在仓库根目录：

```bash
python3 scripts/gen-codes.py --monthly 10 --quarterly 5
```

脚本会打印一段 JSON 数组。把条目追加进 `data/codes.json` 的 `codes` 列表（注意逗号和去重），提交并部署 GitHub Pages。

也可一次多生成一些，例如月 15、季 10，再按需发放。

生成用 Python `secrets` 模块，后缀为 6 位大写字母+数字，前缀固定为 `LLE-M` / `LLE-Q`。

## 安全说明（诚实限制）

这是 MVP，**不是安全实现**：

- 校验发生在用户浏览器里，任何人打开开发者工具都能看到请求 `data/codes.json`
- 码明文存在公开 GitHub 仓库，能看源码的人可以自己兑，或绕过前端锁直接打开课页
- 前端锁只能挡住不想翻代码的普通用户
- 没有核销、没有「一码一用」服务端记录；同一码可被多人使用
- 退出解锁只清本机 `localStorage`，不影响别人

后续若要上真支付（微信官方收款、一单一码、服务端核销），另开方案，不要在本静态站硬接支付 API。
