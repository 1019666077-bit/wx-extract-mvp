### 3.8 若要坚持官方挂载：主体、资质、go / no-go

本节回答「要不要升有限公司 / 找有资质公司」。**不是本周待办。** 读完应能判断：空壳公司解决不了木鱼挂载。

#### 官方组件同时要什么

据开放文档，视频内挂载大约要**同时**成立：

| # | 条件 | 个体户现状 | 仅升有限公司能否解决 |
| --- | --- | --- | --- |
| 1 | 小程序已认证 / 备案 / 上架 | 已满足 | 不必为这三项开公司 |
| 2 | 视频号已认证，且与小程序 **USCC 完全一致** | 未企业认证；官方：**个体户暂不支持视频号企业认证** | **能**：有限公司才有资格走企业认证（蓝 V），再把小程序迁到或开在同一信用代码下 |
| 3 | 小程序服务类目 ∈ 官方开放名单（金融 / 交通 / 餐饮等约 19 项） | 工具 > 信息查询，**不在名单** | **不能**。公司执照不等于金融 / 运输 / 餐饮类目 |
| 4 | 该二级类目的**行业真资质**有效（文档：无免资质类目） | 无，也不该有 | **不能**，除非真去做银行 / 保险 / 餐饮 / 网约车并拿证 |
| 5 | 其它门槛（文档还写过日均活跃等，以后台当时为准） | 未测 | 开公司不自动满足 |

**结论：升有限公司只可能打开第 2 扇门（视频号企业认证 + USCC 对齐）。木鱼仍是工具查询，第 3、4 扇门关着。官方挂载仍然走不通。**

#### 服务菜单呢？

助手已显示「认证主体条件不满足」。有限公司 + 蓝 V **有可能**让部分号看到服务菜单（运营文常说企业认证），但认证指南把服务菜单写成政府 / 事业单位 / 事业媒体 / 企业媒体——**普通工具公司不在稳妥名单里**。即使开通，也只是主页一键，不是视频内组件。用几个月办公司去赌一个未承诺入口 = 空壳幻觉。

#### go / no-go

| 选项 | 裁决 | 理由 |
| --- | --- | --- |
| W0–W12 为官方挂载升有限公司 | **no-go** | 花时间办证，木鱼类目仍不够；直接偷走周更 |
| 买 / 挂靠「有金融或餐饮资质」的公司来蹭类目 | **no-go** | 假升级 + 合规风险；产品不是那个行业 |
| 把木鱼改成开户预约 / 点餐页骗组件 | **no-go** | 明确不做 |
| 12-20 评审时，若仅搜已通、仍痛「多一步搜」，再单独评估公司 | **可议，不是现在** | 只允许评估**服务菜单不确定性**，不得评估「空壳 + 假类目」 |
| 现在走仅搜 | **go** | 唯一已核实、当天能用的水管 |

**空壳公司幻觉（对照用）**：以为「有个章就能挂小程序」。官方要的是**行业类目 + 真资质 + 双边认证一致**，不是「从个体户换成有限」四个字。

**执行者红灯**：过去 6 周发不出每周 2 条 → 减范围，**不要加赛道、不要办公司**。厌倦功德卡：支柱 B ≥50%。连不出镜短视频都无法忍受：海外纸面 + 休息。

一句话止损：

> 搜一搜 / 支付 / 双场内容结构堵死 → 认真换赛道（海外优先，其次编剧工具，禁止游戏 / 短剧 / 电商）；仅搜在跑但 8 周后仍无留存也无收入 → 换同赛道下一款实验品；官方挂载不通 ≠ 换赛道；未到评审日且未亮红灯 → 不准换，包括不准矩阵、不准为空壳公司开工。

## 6. 诗句 / VOA（转化设计一句话）

> **同主体、同为工具类小程序：视频号一键挂载与服务菜单和木鱼一样结构不通。过审只上架、只走搜一搜 / 分享卡片；不为它们改类目、不开第二内容号、不把「绑定视频号」写成增长动作。**

它们走**合规日历**，不走增长。过审 ≠ 换主航道。旧文「一号最多 10 个小程序再绑定」在关联入口本身不可用时是空话——不要把绑定窗当待办。

### 6.1 诗句对对
