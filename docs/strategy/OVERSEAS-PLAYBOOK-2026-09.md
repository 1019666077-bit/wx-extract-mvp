## 0. 先读这一页

**和国内的关系**：国内管道与海外管道几乎不共享流量、支付、合规、语言、品牌。共享的只有时间、Cursor / Grok Pro+ 额度、和「能把东西做出来」的手。一人公司里没有并行，只有轮转。

**闸门前**：零产品代码、零新仓、零正式产品域名、Cursor **0%** 给海外脚手架。国内未接通时「偷偷开海外」= 用未来的自己给现在的自己发工资。

**过闸后第一句动作（不要提前演练）**：用已经 KYC 通过的 MoR 开一个 **7 天可向陌生人收费** 的英文单页工具，公开价，$9–$29 一次性或 $5–$12/月，发一次 Product Hunt / 一次 X。然后每周一个可见改进。国内周更跌破 2 条，立刻停海外代码。

**本文干什么**：规定未过闸时能准备什么、过闸后 30/60/90 天做什么、失败时转向哪里。不规定本周拍哪条木鱼——那是国内篇。

## 1. 与国内关系（写死）

```text
国内收银 ──不依赖──→ 海外工具
海外 MRR ──不依赖──→ 国内转化人格
         ╲         ╱
    你的时间 + Pro+ 额度
```

- 视频号挂载不需要 X followers。  
- 英文用户不买功德鸡汤；Builder 信誉要从英文交付记录长出来，不能从木鱼粉迁移。  
- **VOA 不是出海。** 内容是英文，市场与支付仍在微信。VOA 代码仓禁止塞海外 SaaS。  
- 木鱼英文版、AI 伴侣、「师父」域名的 .com = 黑名单，不是第一款。

国内 90 天事业仍是：小红书公式 → 视频号母带 → **搜一搜** → 木鱼。海外是 **12–24 个月变现上限**，资格赛过了才上场。匹配分（TRACK-CHOICE）：当前国内 8，海外现在开只有 4——不是海外永远差，是**现在**开会把成功率打穿。官方挂载不通 ≠ 国内结构失败。

## 2. 闸门条件（复述，执行以本表为准）

原则：防止永远不开，也防止过早分心。用日期强制评审，用指标决定开闸，用形态限制第一款大小。

### 2.1 强制评审日

- **第一次**：2026-12-20（与国内赛道评审同一天，加一项「海外」）。必须写下：`开 / 冻 90 天 / 结构失败转策略 A`。  
- 若冻：下一评审日再 +90 天，不得无限期口头冻结。  
- 禁止用「再打磨一版木鱼」逃避评审日。  
- **禁止**：把海外周历提前画进国内 W1–W12 的待办列。

### 2.2 绿灯（国内仍健康时，允许抽额外时间做海外 v0）

须 **全部** 满足：

| # | 指标 | 阈值 | 为什么 |
| --- | --- | --- | --- |
| 1 | 等价入口在跑 | 连续 4 周，每周至少 2 条视频号；入口类型按国内篇枚举（个体户默认 **仅搜** 写死）。官方挂载不通**不**单独卡这项 | 管道在，开海外才不是逃 |
| 2 | 管道有人走 | 连续 4 周，每周小程序打开 ≥ **50**（能区分视频号来源则区分；不能则看与发布时间相关的打开峰值） | 低于此仍是自嗨发布 |
| 3 | 收银或强留存 | **二者取一**：木鱼（含兑码）近 30 天实收 ≥ **¥1,000**；**或** 7 日敲击留存 ≥ **15%** 且 WAU ≥ **300** | 愿付或真用 |
| 4 | 周更稳定 | 过去 8 周有效发布 ≥ **16** 条，无连续 14 天停更 | 出海最怕坐不住重复劳动 |
| 5 | 时间与额度有余 | 保住国内篇 §8 的 14h 预算后，额外挤出 ≥ **8** 小时；且明确不把 Pro+ 打满 | 没有余量就没有第一款 |
| 6 | 收款预通 | Paddle / Lemon Squeezy / Polar 之一 KYC **已通过**，或海外 / 香港主体可收款。**只做 KYC 可提前，单独限 1 个周末，不算产品立项** | 避免产品做完无法收款 |
| 7 | 题目够小 | 第一款 7 天内可向陌生人收费：无自研账号体系、无自定义 ML、无中文市场依赖 | 防止长成第二份全职 |

绿灯开闸后：第一款只占每周 **额外** 8 小时，不得挪用国内内容 4 小时、不得挪用木鱼产品 3 小时。周更跌破 2 条 → **立即停海外代码**。

### 2.3 黄灯（最常见）：继续冻

未绿未红：管道在动但没到阈值。默认继续国内策略 C。心态用休息解决，**不用开仓解决**。

### 2.4 红灯（国内结构失败）：海外从「锦上添花」变成续命

以下 **任一** 在评审日成立，且国内 W6 改包装无效，则必须转向（见 §6），避免永远不开：

- **搜一搜打不开木鱼**，或小程序下架 / 名称不可用，且 30 天内无合规解法。官方视频内挂载 / 服务菜单对个体户已核实不可用——那是入口降级为仅搜，**不是**本条红灯。  
- 内容无论修心还是解压包装，连续 6 周自然播放中位数接近零，同时小红书失效。  
- 支付与兑码双死。  
- 主体资质导致三个小程序都无法继续运营。

此时执行 §6 转向清单的 W1（**先收款通道**），国内内容降到每周 0–1 条保养。仍禁止游戏 / 短剧 / 电商矩阵「博一把」。

### 2.5 一句话闸门

> **连续 4 周仅搜入口写死、每周 ≥2 条且带来 ≥50 次小程序打开，并且（月实收 ≥¥1000 或 WAU≥300 且 7 日留存≥15%），才准开海外第一款；若搜一搜/支付/内容被结构堵死，则评审日必须转向出海——此前零代码。官方挂载对个体户不可用，单独不构成转向。**

## 4. 过闸后：第一款怎么选

以下章节 **默认冻结**。只有 §2.2 全绿，或 §2.4 红灯转入策略 A 之后，才变成待办。不要在国内 W0 打印这部分当清单。

### 4.1 选型原则（levelsio 风格，贴他的手）

他真正能迁移的不是微信流量，是：**能把小工具做上线、能把内容公式收成可复制交付、能用 AI 代理批量堆内容（VOA 已证明）、能接受兑码式收款手感**。不是出镜、不是英文十年账号、不是投流。

第一款必须同时满足：

1. **7 天可向陌生人收费**：打开就能用，付完立刻解锁。  
2. **单页或极少页**：无自研账号、无「先做社区」、无自定义模型训练。  
3. **英文 UI + 英文定价页**；不依赖微信登录、不依赖国内短信。  
4. **产品即内容**：changelog / 前后对比截图能发 X，不需要出镜口播。  
5. **命名隔离**：产品名、域名、X 账号不得出现「师父」「功德」「木鱼」。  
6. **中国用户不是第一客户**：可以买，但不为他们做微信支付、不做中文落地页（避免又开一条国内增长线）。  
7. **Pro+ 吃得起**：生成功能要有硬上限；禁止「无限畅聊」。

**白名单形态**：转换器、检查器、生成器、单页计算器、文件处理、习惯打卡的极简 SaaS、给作者的大纲 / 集卡输出（卖铲子）。  
**黑名单形态**：又一个木鱼英文版、AI 聊天伴侣、要训练数据、要靠英文短视频人设才能卖、先做社区、小游戏、短剧站、跨境电商。

打分是「过闸后做第一款的合适程度」，不是现在就开工。分数 1–5，只作排序。

| # | 方向 | 一句话产品 | 为何贴他 | 主要风险 | 过闸优先级 |
| --- | --- | --- | --- | --- | --- |
| **A** | 单页检查器 / 转换器 | 例：OG / slug / UTM / 隐私政策检查、时区会议条、JSON→CSV | 最像 levelsio；7 天能收费；changelog 好写 | 红海、定价薄；要靠持续可见更新 | **第一候选** |
| **B** | 习惯 / 打卡微工具 | 例：一个习惯、公开 streak、到期提醒；英文，Stripe 订阅 | 国内木鱼 / VOA 打卡手感可迁移到「习惯」抽象，但 UI 与文案必须全新 | 做成又一个习惯 App 就死；通知与账号容易膨胀 | 第二。必须砍到「无账号 + 魔法链接」 |

### 4.3 技术栈建议（过闸才建仓）

目标：一个周末能收费，而不是正确架构。

| 层 | 建议 | 不要 |
| --- | --- | --- |
| 前端 | 单页：静态 HTML 或 Next.js 仅前端；部署 Vercel / Cloudflare Pages | 自建 K8s、自研组件库、小程序壳 |
| 后端 | 尽量无。必须有则 serverless 函数 + 现成数据库（Supabase / 甚至无库只 webhook） | 自研用户系统、微服务 |
| 登录 | 魔法链接或 MoR 结账后邮件发密钥；能免则免 | 微信登录、短信、OAuth 全家桶 |
| 支付 | **Paddle 或 Lemon Squeezy 或 Polar**（MoR，大陆个体户比直连 Stripe 现实） | 第一款直连 Stripe 死磕；不接微信支付「顺便国内也能买」 |
| 域名 | 过闸后再买 .com / .app；DNS 指到托管 | 闸门前注册 |
| 邮件 | 交易信：MoR 自带或 Resend / Postmark | 自建 SMTP |
| AI | 若候选 D：官方 API + **硬性次数上限** + 成本熔断 | 无限畅聊、自托管大模型、用 Pro+ 额度替用户生成 |
| 仓与品牌 | **新仓、新 GitHub 账号亦可**；与 `wx-extract-mvp` 隔离 | monorepo 塞进 VOA |
| 语言 | UI 英文；代码注释随便 | 先做 i18n 框架 |

个体户税务 / 结汇不在第一款范围里写完。过闸后第 1 个周末只要求：**能合法收到一笔测试付款**。税务记到「额外 8 小时里的 1 小时查阅」，不够就请代理，不自研财务系统。

### 4.4 获客与支付（过闸后）

**支付顺序（不可逆）**

1. KYC 通过（可提前那个周末）。  
2. 定价页公开：$9–$29 一次性，或 $5–$12/月。不要「私聊询价」。  
3. 用自己的第二张卡走通一笔，记录收据。  
4. 再向陌生人卖。没有第 3 步 = 产品未上线。

**获客（第一款只有这些，别加）**

| 渠道 | 怎么用 | 不做 |
| --- | --- | --- |
| 产品本身 | 免费可用一截 + 付费解锁；每次更新写 3 句 changelog | 未收费先做积分社区 |
| X | 过闸后可开**产品号**（闸门前禁止「正式产品号」）。发 before/after、收入或构建日志 | 中文修心人设混发；不买粉 |

| 目录站 / 小 SEO | 一个词的落地页标题 | 内容农场、中文 SEO |
| 邮件 | 购买者收据 + 更新 | 未上线先攒 newsletter 当进度 |

| D1–2 | 从 §4.2 锁定 **一个** 方向（默认 A）；买域名；建**新**仓 | 仓是空的也行，但必须新 |
| D3–7 | 最小可用：输入 → 输出 → 定价页 → 结账 | 陌生人不用登录就能完成一次付费尝试 |
| D7 | 自己付款测试 | 收据在邮箱 |
| D8–14 | 公开价上线；PH 提交一次；产品 X 号发 3 条构建帖 | 有公开 URL 与价格，不是「私有 demo」 |
| D15–30 | 每周一个可见改进（用户能看见，不是重构）+ 三次英文更新 | 不新开第二款 |

**30 天止损**：若无法完成一笔**非自己**的付款，且访问量接近 0——允许换 **同一个原则下的另一题**（仍是 A 类），不允许升级成平台。国内周更若已跌破 2 条，先停海外救国内，除非处于红灯续命。

### 5.2 Day 31–60 · 证明有人反复用

| 动作 | 完成标准 |
| --- | --- |
| 继续单款 | 第二款产品禁止 |
| 留存 | 有任意「同一人第二次打开或第二次付费」的记录 |
| 客服 | 标准英文回复 5 条，存在仓库 `SUPPORT.md`，不承诺私有定制 |
| 成本 | AI 类功能设置日上限；账单超预想即关生成 |

**60 天止损**：MRR < **$100** 且无复用用户 → 砍功能到更小，或换题一次。禁止此时开始拍英文口播、上数字人、做中文版「双市场」。

### 5.3 Day 61–90 · 决定加深还是冻

| 情况 | 动作 |
| --- | --- |
| MRR ≥ **$200** 或有明确复购 / 月订 | 加深同一款：一个最被用到的功能 + 持续 changelog。仍不准第二款 |
| MRR < $200 且周活无法证明有人反复用 | 砍掉或改题；**不**平行启动国内新 IP，也**不**把木鱼停掉去 All-in（除非国内已红灯） |
| 国内周更跌破 2 条 | 立即停海外代码，回到国内篇 |

90 天结束写一行决策：`继续单款 / 冻海外 90 天 / 换白名单内下一题`。不要在这里发明矩阵。

### 5.4 过闸后一人周时间（绿灯、国内仍健康）

| 块 | 小时 | 说明 |
| ---: | --- | --- |
| 国内内容 + 挂载 + 四数 | 5.5 | **不可挪用** |
| 木鱼产品 | 3.0 | 不可挪用去写海外 |
| 诗句 / VOA 合规 | 0–3.5 | 无卡死则压缩 |
| 海外 v0 | **8.0** | 建造 + 英文更新 + 支付后台。含在「额外」里；若一周挤不出 8h，海外停不是国内停 |
| 缓冲 | 1.0 | 仍留给生活 |
| 合计上限 | ≤20 短冲 | 不能连续 4 周 >18h，否则执行者红灯 |

Cursor：海外开闸后最多占当周额度 **30%**，且国内缺陷仍优先。感觉打满：砍海外生成功能，不砍国内周更。

红灯续命（策略 A）时：国内 0–1 条保养；W1 **只做收款 KYC**，过不了则策略 A 失败，回到休息或中文编剧工具（§6），不要空等产品灵感。

## 6. 闸门失败（结构堵死）的转向清单

国内红灯不是「终于可以凭兴趣做 levelsio」的奖赏，是公司续命。按顺序试，**禁止跳到匹配分 ≤4 的热闹**（短剧制作、虚拟人带货、电商、小游戏矩阵）。

### 步骤 0 · 停假升级

- 国内内容降到 0–1 条保养，公式仍不出镜。  
- 不新开游戏、不矩阵、不上数字人、不橱窗。  
- 诗句 / VOA：只维持已上架，不增长。

### 步骤 1 · 先收款，后产品（海外路径）

| 天 | 动作 | 失败则 |
| --- | --- | --- |
| 1–2 天（一个周末） | Paddle / Lemon Squeezy / Polar KYC，或香港 / 海外主体能否收款 | **立刻失败**，不要「先做产品再想怎么收钱」→ 去步骤 2 |
| 通过后 7 天 | 仍按 §4 选 **A 类**单页工具，公开价上线 | 不要做木鱼英文版「安慰自己还在修心」 |
| 其后 | 走 §5 的 30/60/90，但国内不再占 5.5h 内容块 | 周活与 MRR 止损线仍生效 |

### 步骤 2 · 海外收款走不通：中文编剧工具（赛道 7）

支付留在微信（虚拟支付或兑码，主体现成）。卖铲子，不拍短剧。

- W1：写清付费点（不是全能编剧）；定价；微信内能收款再开放生成。  
- W2–W4：粘贴大纲 → 出集卡；10 个种子用户，不公开卖。  
- **获客不得用木鱼号讲短剧。** 两套人格一起死。  
- Pro+ 设上限，禁止无限畅聊。  
- 木鱼号若还在：最多 0–1 条保养，不导流到编剧工具。

### 步骤 3 · 步骤 1 与 2 都走不通

停机休息。写决策日志。不要用个人号硬上虚拟人带货「最后一搏」。公司续命失败时，正确动作是停，不是换一张更热闹的牌。

### 明确不会出现在转向清单里的东西

短剧制作公司、AI 漫剧矩阵、数字人口播带货、香烛念珠电商、微信小游戏 IAA/IAP、为诗句开内容号当主业、把 VOA 当出海。

## 7. 过闸后第一句动作（备忘，未过闸不要做）

绿灯全勾后的第一个工作块，按顺序：

1. 打开 MoR 后台，确认能收款（已 KYC）。  
2. 从纸面库存挑一个 **A 类**标题；若库存为空，用「单页检查器」占位，不要现场发明平台。  
3. 注册域名（这时才允许付款）。  
4. 新仓 + 单页：输入、输出、价格、结账按钮。  
5. 自己买一次。  
6. 公开 URL；PH / X 各一次。  
7. 日历写：国内本周仍须 ≥2 条木鱼视频——海外再兴奋也先剪国内母带。
