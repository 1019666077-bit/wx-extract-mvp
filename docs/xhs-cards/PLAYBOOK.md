## 1. 热门拆解（公开规律 × 本号数据）

下列公开口径来自 2025–2026 常见运营文 / 内容方法论（封面 3:4、标题钩子、轮播一图一要点、发布后 1h 赛马、相似内容提醒等），**不是**小红书官方原文。阈值当参考，以创作者中心实际数据为准。

### 1.1 封面停滑：信息流里的 0.3 秒

瀑布流里用户先看到的是 **3:4 竖封面 + 标题前若干字**。停滑靠三件事同时成立：

1. **主体一眼能认**：实景/静物氛围，不是抽象色块、不是细碎纹理。本号赢家 = 上半实景；对照组黄黑抽象 ≈ 滑过去。
2. **下半色块当扩音器**：标题落在实色区，字大、对比高、手机缩略图仍可读。公开建议封面主标题约 3–10 字、整封面文字不超过两行；本号把「完整钩子句」放色块里，比把字撒在画面上更稳。
3. **和邻居不像**：修心赛道一刷全是佛像、空枕、雾气人背影。结构可同，**素材必须换场**。下一篇：**禁止佛像、禁止空枕**。

本号可复用的封面骨架（学结构不抄图）：

```
┌─────────────────────┐
│                     │
│   上  氛围实景 ~60%  │  ← 静物/光/天气，无脸或背影即可
│                     │
├─────────────────────┤
│  下  实色块 ~40%     │  ← 一色到底，粗体标题 1–2 行
│  主句               │
│  （括号好奇句）      │
└─────────────────────┘
```

「上图下文 / 夜灯茶杯」与「上氛围 + 下色块」是同一家族，差别只在色块是否够实、字是否够大。新篇「心债」已走夜灯茶杯，下一张封面换场景、换色相，避免连续两张都是「室内暖光静物」。

色块建议轮换，**不要连用赢家那块深绿**：黛青、靛蓝、墨蓝、绛褐、赭石、深朱红偏褐。每篇一个主色，内页黄纸保持不变，账号辨识靠黄纸内页，不靠封面克隆。

### 1.2 标题钩子：前 8 字定生死，括号定点击

公开常见口径：

- 笔记标题上限常写 **20 字（含标点）**，信息流往往只完整露出前 8–12 字，核心词必须前置。
- 搜索侧：一个主词，不要堆三个主题。
- 情绪赛道高点击句式：权威来源、反常识、人群点名、未完成信息（括号 / 很多人不知）。

本号赢家同时做了三件事：

| 零件 | 赢家怎么用 | 为什么有效 |
| --- | --- | --- |
| 权威前缀 | 「师父说」 | 修心赛道的信任捷径，像「医生说」「老师傅说」 |
| 未说完的大词 | 「有一种功德非常大」 | 承诺稀缺，却不把答案写在标题里 |
| 括号第二钩 | 「（很多人不知道）」 | 制造信息缺口 + 点名「你可能是漏掉的那群人」 |

对照组同题去括号 → 只剩陈述句，瀑布流里像一条普通鸡汤，几乎没量。

**操作规则：**

- 标题 16–20 字（含括号）。赢家原句约 21 字；若客户端仍限 20，宁可缩主句、**保住括号**。例：`师父说有种功德非常大（很多人不知）`。
- 括号用「认知差 / 人群 / 反着来」，不要用「必看」「绝了」「封神」。
- 前 8 字放搜索词或权威句，不要把括号放到最前（括号是点击，不是收录）。
- 标题与封面色块文字 **同句**，方便封面 OCR 和标题互相加持。

### 1.3 轮播节奏：6 张黄纸，一图一念

公开建议图文轮播 4–9 张、统一 3:4；太多易滑走，太少不像「可收藏卡片」。本号套 A 已验证 **6 张黄纸** 的体量；套 B 7 张也可以，但下一篇默认 **封面 1 + 黄纸内页 6 = 共 7 张**（封面即第 1 张，可点进后再滑黄纸）。

若想更短：封面仍用氛围+色块，黄纸压成 5 张（总 6）。不要少于 5 张内页——鸡汤号收藏来自「可截图金句」，张数太少不像一套。

内页节奏（固定，换词不换骨）：

| 张 | 功能 | 写法 | 禁忌 |
| --- | --- | --- | --- |
| 黄 1 | 重锤标题 | 比封面更短的 4–8 字，可截图 | 不要再堆括号 |
| 黄 2 | 场景痛点 | 具体时刻（夜里、一早、饭桌），让人觉得「说的是我」 | 不要抽象「人生」「命运」 |
| 黄 3 | 反常识 | 把常做的「表面修行」轻轻揭穿 | 不要骂人、不要恐吓改命 |
| 黄 4 | 落到身上的一寸 | 家人 / 口 / 气 / 第一念，必须可感 | 不要经文整段 |
| 黄 5 | 今晚/今天只做一件 | 一个小动作，30 秒内能做 | 不要清单 7 条；不要「功德+1」 |
| 黄 6 | 收束 + 软植入 | 一句余味 + 末行「天天敲木鱼小憩」 | 不要二维码、不要关注引导堆砌 |

左滑动力：每张只说 **一个念头**，末字落在「还没说完」或「下一张有做法」。第 5 张给做法，第 6 张才能停。

正文（笔记文字区，不是卡片）：前 50 字重复封面钩子 + 一句场景；中间 3–5 短段，不要把 6 张全文再贴一遍；结尾一个轻问题（「你今晚还想说的那句话，是不是可以留到明天？」）。禁止求赞、@好友、互暖。

标签：1 个大词（如修心）+ 3–4 个长尾（口业、让步、晨起、比较心、电子木鱼）+ 避免纯泛词堆砌。

### 1.4 发文间隔：同题同小时是在自己赛马

公开常见口径：

- 发布后约 5 / 30 / 60 分钟分层赛马，前 1 小时决定能否进更大池。
- 黄金时段参考：工作日 12:00–13:30、19:30–22:30；最终以创作者中心「粉丝活跃」为准。
- 稳定期更吃质量：每周 3–4 条精品，优于水文日更。
- 主题 / 画面 / 句式高度相似，可能触发「近期笔记较为相似」类提醒，并在约 7 天内下调新笔记推荐（运营文转述，非法律条文）。

结合本号一手：

- **禁止**同一选题两条几乎同时发（赢家 vs 无括号那条，等于把初始流量劈开，且差封面那条纯浪费）。
- A/B 只测 **一个变量**：要么只换封面，要么只换括号；间隔 **≥18–24h**，并在标题里让系统看出不是同一篇。
- 「心债必须当天还」观察窗：**发布后满 24h** 再发下一篇修心卡。若它也起量，下一篇拉开语义（口、让、晨念），不要再做「当天必须还」近亲。
- 默认节奏：**隔天 1 条** 修心黄纸；中间若要发，发完全不同画风（例如产品使用感、实拍敲击），降低相似判定。
- 差数据笔记不要立刻删；优先设仅自己可见。删除伤权重的说法在运营圈很普遍，本号小样本更没必要删。

### 1.5 撞题风险：平台相似 + 赛道撞车 + 自己踩禁区

三层风险，分开管：

1. **自己撞自己**：24h 内两条「师父说…功德/心债」；封面都是室内暖光静物；黄纸句式同一套只换数字。→ 换主词、换场景、换色相。
2. **赛道撞车**：信息流里同期大量「回光、安住、功德+1、心债」。这些词本号已用或已禁，再发像跟风搬运。→ 用更窄的身体词：口过、收口、第一念、让三分、比较心。
3. **合规 / 社区**：夸大改命、治病、算命、做法；诱导互动；站外导流（微信搜、二维码）。修心文案主打 **情绪与当下的一小步**，不承诺福报到账。公开佛系赛道建议也强调：心理学 + 传统文化表述，不走封建迷信。

搜索词可埋：修心、口业、让步、晨起、比较心、静心。少用：改命、转运、消业（过重，易审）。

## 2. 热门标题句式模板（10 个，可填空）

填写后控制在 16–20 字。括号保留。`{权威}` 默认「师父说」，可换成「老师傅说」「老辈人讲」轮换，避免连续三篇都「师父说」。

1. `{权威}有一种{X}非常大（很多人不知道）`  
   例：老师傅说有一种口过非常重（很多人不知道）

2. `{权威}从不讲{大词}，只让人先{小动作}（听懂的人少）`  
   例：师父从不讲福报，只让人先闭嘴（听懂的人少）

3. `有一种{习惯}，比{常见动作}更积福（{人群}更要看）`  
   例：有一种让步，比争赢更积福（脾气急更要看）

4. `{时间点}不做{这件事}，一天都在漏（很少人当真）`  
   例：一早不管第一念，一天都在漏（很少人当真）

5. `真正{结果}的，不是{表面修行}（很多人反着来）`  
   例：真正留福的，不是多说好话（很多人反着来）

6. `{情绪痛点}的人，先把{口/气/念}收住（比求更有用）`  
   例：夜里睡不着的人，先把口收住（比求更有用）  
   （勿写空枕、勿写回心/安住）

7. `会{表面}的人很多，会{落点}的人很少（一句就够）`  
   例：会求的人很多，会收口的人很少（一句就够）

8. `{X}不过夜（很多人不当回事）`  
   例：口过不过夜（很多人不当回事）  
   （勿写成心债不过夜）

9. `{数字}个字：{短金句}（比{夸张对比}要紧）`  
   例：五个字：先看光再看手机（比求一百次要紧）

10. `你不是缺{福/静}，是一直在{漏/比/说}（修很久的人更要看）`  
    例：你不是缺福，是一直在比（修很久的人更要看）

**不要填进模板的词：** 回心、安住、功德+1、心债、金刚经四句、回光返照、渡人先渡心。

## 3. 下一篇原创选题 × 5

均避开禁区与已用主句。封面：**非佛像、非空枕**；下半色块每篇换色。内页：黄褐纸纹 + 粗体中文，6 张。末卡一句产品名。

建议发送顺序：先发 **口过不过夜**（离「心债」最近但仍是口而非心，测括号句式是否可迁移）→ 看 24h 点击与互动 → 再在「让三分 / 第一念 / 收口 / 比较心」里挑和评论区最共鸣的一条。若「心债」24h 互动率也 ≥5%，跳过口过，直接发语义更远的「晨起第一念」或「比较心」，降低相似。

### 选题 1 · 口过不过夜

- **标题草案：** `口过不过夜（很多人不当回事）`（12 字，可前置权威：`师父说口过不过夜（很多人不知）`）
- **封面氛围（一句话）：** 窗台一只旧铜铃被风吹偏，铃舌停住，玻璃上有细雨痕。
- **下半色块：** 黛青（蓝绿，明确区别于赢家深绿）
- **黄纸 6 卡：**
  1. 口过不过夜
  2. 白天说出去的话，夜里还在心里转
  3. 不是把声音收回来，是今晚不再补那一刀
  4. 对家人的一句重话，比外面求来的更沉
  5. 今晚只做一件：想说的火，先过一盏茶
  6. 心平了再开口。天天敲木鱼小憩

### 选题 2 · 让三分不是输

- **标题草案：** `有一种让步比争赢更积福（脾气急更要看）`
- **封面氛围（一句话）：** 被雨打湿的青石阶，两片落叶叠在一起，没有人。
- **下半色块：** 绛褐
- **黄纸 6 卡：**
  1. 让三分不是输
  2. 争赢的那口气，走得最远、也最费神
  3. 路让人一步，话留半句，场就宽一寸
  4. 家里让的那一次，比外面做的样子更真
  5. 今天只让一件小事，让完不再找补
  6. 退一步，心先宽。天天敲木鱼小憩

### 选题 3 · 一早第一念

- **标题草案：** `一早第一念比求一百次要紧（很多人反着来）`
- **封面氛围（一句话）：** 晨窗一条冷光，香几上线香刚熄，一缕青烟还没散尽。
- **下半色块：** 靛蓝
- **黄纸 6 卡：**
  1. 一早第一念
  2. 眼还没睁，心已经开始算昨天的账
  3. 第一念若是怨，后面再修也像补洞
  4. 先看光，再看手机——就这一下
  5. 起身三息，把心放回身上，再开口
  6. 新的一天从这一念开始。天天敲木鱼小憩

### 选题 4 · 福从收口来

- **标题草案：** `福气都从收口来（会说话的未必会）`
- **封面氛围（一句话）：** 半掩的旧木门，门缝里一线暖黄，门外青苔，看不见室内陈设。
- **下半色块：** 赭石
- **黄纸 6 卡：**
  1. 福从收口来
  2. 福不是求来的，多半是从嘴里漏掉的
  3. 抱怨一句，心就开一个口
  4. 好事说满，反而散；半句留着，才有余味
  5. 今天少说一句不满，说过的不再解释
  6. 嘴收住了，福才留得住。天天敲木鱼小憩

### 选题 5 · 比较心最耗神

- **标题草案：** `真正耗神的是比较心（修很久的人更要看）`
- **封面氛围（一句话）：** 庭院一口旧水缸，水面只倒影出树梢和一块天，无脸。
- **下半色块：** 墨蓝
- **黄纸 6 卡：**
  1. 比较心最耗神
  2. 一看别人修得快，自己的场先乱
  3. 修不是排行榜，多看一眼就漏一寸
  4. 你的一盏灯，照自己脚下就够
  5. 今天不比任何人，只过好眼前这一息
  6. 只管自己这一下。天天敲木鱼小憩

## 4. 发布检查清单（每篇）

发前：

- [ ] 标题 16–20 字，有括号，前 8 字含主词
- [ ] 封面 = 上氛围 + 下实色块，**不是**佛像、空枕、黄黑抽象、赢家同款深绿
- [ ] 色块字与标题同句，缩略图能读
- [ ] 黄纸 6 张一图一念，无金刚经整段，无回心/安住/功德+1/心债
- [ ] 产品名只在末卡最后一行
- [ ] 无二维码、无「微信搜」
- [ ] 距上一条修心图文 ≥18h；未与「心债」抢同一个晚上

发后 1h：

- [ ] 用小号搜标题全文，确认能搜到
- [ ] 自己留一条 15 字以上的真问题评论（不求赞）
- [ ] 真实评论 5 分钟内回，不互暖

24h 复盘（对照本号赢家，不对照百万大号）：

| 看什么 | 本号合格参考 | 不及格时改什么 |
| --- | --- | --- |
| 互动率（赞评藏 / 阅读） | ~5%+（赢家 ~7%） | 先改封面色块与括号，不先改选题 |
| 阅读 | 看相对值：是否接近赢家量级 | 过低且互动也低 = 没停滑；过低但互动高 = 覆盖不够，可换时段再测新题 |
| 收藏 | 有收藏说明黄纸可截 | 无收藏 = 内页不够「一句一图」 |

## 5. 明确不做什么

- 不生成、不附带任何配图文件（封面与黄纸由执行方按本文自制）。
- 不把本号赢家佛像封面当模板再出一张「换字版」。
