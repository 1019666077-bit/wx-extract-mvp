## 1. 短研报

### 1.1 对标爆款结构（《师父说有一种功德非常大》，约 6k 赞）

| 层 | 爆款做法 | 作用 |
| --- | --- | --- |
| 权威开场 | 「师父说……」 | 借师承口吻，降低鸡汤感，提高可信 |
| 好奇缺口 | 「有一种功德非常大」+ 副标「能刷到绝非偶然」 | 封面只给判断、不给答案，逼人滑第二张 |
| 分点展开 | 黄纸粗体竖卡，一卡一义（是什么 / 不是什么 / 怎么做） | 轮播停留；金句可截图转发 |
| 收尾祝福 | 愿语 + 轻点产品名 | 情绪闭环；转化藏在最后一张 |

视觉锚点：黄褐纸纹、右上桂花枝、超粗黑体、莲纹分隔、底部小莲。无二维码、无微信搜、无 App 截图。

### 1.2 套 A / 套 B 已占用（本篇禁用）

回心、安住、功德+1、敲一下、把心拉回来、回光返照、场清了、轻功德、渡人先渡心、心安装福报。  
禁止整段《金刚经》四句偈。封面不再复用「有一种功德非常大」。

### 1.3 三个可原创选题

1. **心债必须当天还**（入选）  
   隐喻：过夜的那口念头会自己变重。动作：松手 / 不接 / 这一声落地。  
   适合木鱼：木鱼本就是「日课」器具，「当天还」= 睡前 3 分钟小憩，产品名「天天敲木鱼小憩」自然贴上，不必说「敲一下」「功德+1」。

2. **少说一句的功德**  
   火气上来先把那句话咽回去。社交场景强，但落点在「口业」，和木鱼声的身体仪式较远，软转化要绕一圈。

3. **睡前把念头收回来**  
   失眠痛点准，但「收回」易撞上套 A 的「拉回来 / 回心」，辨识度不够。

**入选理由：** 「债」是新词，不撞功德鸡汤；「当天还」自带日课节奏；「过夜就变重」可截图；末卡一句产品名即可完成「今晚少扛一笔」的转化，不硬广。

## 2. 发帖文案

**标题：** 师父说有一种债必须当天还

**正文：**

师父说，人这一生欠得最多的，不是钱。  
是那口没咽下去的气，那句没说完的话，那件放不下的小事。  
过夜，就会变重。

不是找人算账，也不是把对方说动。  
念头来了，你可以看见它，但不必伸手接。  
少接一念，少扛一笔。

心债当天还。  
今晚少扛一笔。

**话题标签：**

#修心 #修行 #自我成长 #传统文化 #智慧人生 #思维提升 #开悟 #禅意生活体验 #渡人渡心渡自己 #人生就是修行 #心债 #睡前功课

（产品名只出现在末卡：天天敲木鱼小憩。正文不写微信搜、不放二维码。）
