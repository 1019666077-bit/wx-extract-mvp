# 套 D · 口过不过夜

小红书图文笔记。学「上氛围图 + 下色块 + 括号好奇句」结构，不抄赢家佛像/深绿/薄荷字；封面与内页视觉分离。选题取自 `PLAYBOOK.md` 下一篇优先项。

---

## 1. 短研报

### 1.1 结构（学思路，不抄视觉）

同账号对照：括号钩子 + 上实景下色块停滑有效；无括号的黄黑抽象几乎没量。套 C「心债」已用夜灯茶杯 + 赭褐，本篇必须换场、换色。

| 层 | 本篇做法 | 刻意没做 |
| --- | --- | --- |
| 上半氛围 | 窗台旧铜铃被风吹偏、铃舌停住、玻璃细雨痕 | 佛像、空枕、室内暖光茶杯 |
| 下半色块 | 黛青 `#1A434C` | 赢家深绿、套 C 赭褐 |
| 括号 | （很多人不当回事） | （必看）（绝了）；「不知道」不如「不当回事」贴口过 |
| 内页 | 黄褐纸纹 + 粗体 + 桂花枝 + 莲纹，6 张 | 封面同款实景；黄黑抽象 |

「口/铃声」隐喻：话如铃，风一过就偏；铃舌停住 = 这一句先不要补。不是把声音收回来。

### 1.2 禁区（本篇未用）

回心、安住、功德+1、心债、金刚经四句、佛像、空枕、连续室内暖光茶杯。  
套 A/B 主句也不复用。无二维码、无「微信搜」。产品名只在末卡一句。

### 1.3 标题字数

`师父说口过不过夜（很多人不当回事）` = 17 字（含标点）。前 8 字含「口过」；括号保住。

## 2. 发帖文案

**标题：** 师父说口过不过夜（很多人不当回事）

**正文：**

师父说，口过不过夜。  
白天那句话已经说完了，夜里它还在心里转。  
很多人不当回事。

不是把声音收回来，  
是今晚不再补那一刀。  
对家人的一句重话，比外面求来的更沉。

今晚只做一件：想说的火，先过一盏茶。  
心平了，再开口。

你今晚还想补的那一句，是不是可以留到明天？

**话题标签：**

#修心 #口业 #修行 #自我成长 #传统文化 #智慧人生 #禅意生活体验 #少说一句 #睡前功课

（产品名只出现在末卡：天天敲木鱼小憩。正文不写微信搜、不放二维码。）
