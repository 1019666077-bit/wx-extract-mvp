隐私政策与数据说明

最后更新：2026-09-29。这一页说明本站会碰到哪些数据、存在哪里。

1. 一句话总结

本站没有账号系统，也没有自己的服务器数据库。你的学习进度留在你自己的浏览器里，运营者看不到，也收不到。

2. 存在你浏览器里的数据

下面这些内容写在浏览器的 localStorage 里，只在你自己的设备上：

  • 每一课的测验得分、是否完成、作答记录；
  • 打卡日历的日期与连续天数；
  • 错题本里的题目；
  • 你选择的字体（简体或繁体）；
  • 开通状态与到期时间。

本站不把这些内容上传到任何服务器。运营者无法查看、导出或恢复它们。你可以在浏览器设置里清除本站数据，删除后无法找回。

3. 本站不用什么

  • 不设账号，不需要手机号、邮箱或密码；
  • 不写 Cookie 用于跟踪；
  • 不装访问统计、广告或第三方分析脚本（例如 Google Analytics、像素广告）；
  • 不向第三方出售或分享你的学习记录。

4. 会接触到数据的第三方

本站是静态站点，但下面这些环节仍然会让第三方看到你的部分信息：

  • 网页托管：页面由 GitHub Pages（迁移后为 Cloudflare Pages）提供。托管方按其自身政策记录访问日志，其中通常包含 IP 地址。
  • 课文视频：视频文件来自 VOA 的服务器（voa-video-ns.akamaized.net）。只有当你播放视频时，浏览器才会连接过去，VOA 及其 CDN 因此会看到你的 IP 地址与请求信息。视频受 VOA 自己的隐私条款约束。
  • 外部链接：课文页上的「YouTube 备用」与「VOA 原文课文」是外部链接，只有你主动点击才会离开本站。
  • 付款与联系方式：开通是人工收款，付款与发码都在微信里进行。你在微信里提供的信息由你与微信之间处理，本站不保存这些记录。

5. 儿童

本站面向一般英语学习者，不专门面向儿童，也不会有意收集儿童的个人信息。未满法定年龄的使用者请在监护人同意下使用；需要付款时请由监护人完成。

6. 你的选择

  • 不想要任何本地数据：清除浏览器的本站数据即可，功能会回到初始状态。
  • 不想连接 VOA 服务器：不要点击播放视频，改用课文文字与中英对照字幕。
  • 不想留下访问日志：使用你信任的网络环境或浏览器隐私设置。日志由托管方控制，本站无法删除。

7. 政策的变更

这一页可能会更新，更新后在本页发布即生效，顶部的「最后更新」日期会一起改。
